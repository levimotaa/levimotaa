## Fala Cines

**Uma experiência social para quem gosta de cinema.**

O Fala Cines nasceu da ideia de tornar a descoberta de filmes mais divertida e, principalmente, transformar o que acontece depois do filme em parte da experiência.

A plataforma reúne descoberta de filmes, avaliações, listas, feed social e experiências para assistir sozinho, em dupla ou em grupo.

**Stack:** React · TanStack · TypeScript · Supabase · Tailwind CSS · Cloudflare Workers

→ [falacines.com](https://falacines.com)
